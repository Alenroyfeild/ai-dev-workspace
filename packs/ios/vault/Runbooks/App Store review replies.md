# App Store review replies

1. Save the rejection text; note each cited guideline number, the review device and OS, and Apple's exact requests.
2. Reproduce on that device/OS class if possible. Separate what Apple saw from what the app does today.
3. Reply with facts only: what changed or why the behavior complies, where the reviewer can see it (steps, demo account handled through App Store Connect, never pasted credentials).
4. One reply per rejection round; keep the case as one task record so the history stays together.
5. Never submit, reply or change App Store Connect settings without the user's explicit go-ahead in that turn.
